# Finish a checkpoint

Complete only the active checkpoint. Update `docs/TRACEABILITY.md`, `docs/DECISIONS.md`, `docs/TRADEOFFS.md`, and relevant product docs with the code change. Run `make verify` and the checkpoint-specific checks. Write an evidence report using section 13.4 of `docs/BOOTSTRAP_PROMPT.md`: RED, GREEN, gates, coverage, manual checks, open questions, approvals, and gaps.

Do not start the next checkpoint until current gates pass and evidence is written. The founder reviews protected-branch changes and merges them.
